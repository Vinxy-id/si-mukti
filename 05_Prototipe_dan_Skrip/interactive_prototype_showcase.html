🚀 Cara Membuka & Menyunting Prototype di Figma dalam 1 Menit:

1

Gunakan Plugin 'html.to.design'

Buka Figma, jalankan plugin "html.to.design" (tersedia gratis di Figma Community). Plugin ini mengubah file HTML kami menjadi frame, autolayout, dan komponen native Figma.

2

Pilih Tab 'HTML File'

Di jendela plugin, seret (drag & drop) salah satu file HTML dari folder kerja: screen1_mobile_pengrajin.html atau screen2_desktop_webgis.html.

3

Sinkronkan Design Tokens

Gunakan plugin "Tokens Studio for Figma" lalu klik 'Load Tokens' dan pilih file figma_tokens.json untuk otomatis menerapkan Color Styles & Variables resmi.
